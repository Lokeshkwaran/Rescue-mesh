# Rescue-Mesh Project Overview

## Problem

During severe natural disasters, cellular towers, power grids, and communication infrastructure can fail. Rescue teams may struggle to communicate and locate trapped survivors.

## Solution

Rescue-Mesh is an Autonomous Survivor Detection and Communication Network designed for disaster-hit environments.

The system uses smart sensor beacons to form an ad-hoc, self-healing network. The nodes monitor acoustic and vibration signals and transmit survivor alerts and GPS information to rescue teams.

## Key Features

- Self-healing mesh communication
- Acoustic and vibration-based detection
- LoRa long-range communication
- GPS location tracking
- Real-time emergency alerts
- Drone-deployable sensor nodes
- Emergency command dashboard

## Hardware

- ESP32-S3
- SX1262 LoRa Module
- INMP441 Microphone
- SW-420 Vibration Sensor
- MPU6050
- GPS Module
- 18650 Li-ion Battery
- TP4056 Charger

# Rescue-Mesh Mobile Application

## Purpose

The Rescue-Mesh mobile application helps first responders receive real-time survivor alerts and location information.

## Features

- 🚨 Real-time emergency alerts
- 📍 GPS location tracking
- 👤 Survivor information
- ⚠️ Priority-based alerts
- 📡 Communication with the Rescue-Mesh network

## Workflow

1. A sensor node detects a possible survivor.
2. The ESP32 processes the sensor data.
3. The alert is transmitted through the LoRa network.
4. The gateway forwards the information.
5. The mobile application receives the alert.
6. Rescue teams view the survivor location and priority.
